# Assets Guide — Images & Media

Place your local photo assets in this directory.

### Key Photo Files:
1. `hero.jpg` — Fallback image for the full-screen hero section when video is loading or unsupported.
2. `shuklay-portrait.jpg` — Shuklay's portrait photograph displayed in the "Behind the Camera" About section.
3. Project Covers & Gallery Stills:
   - `two-much-cover.jpg`
   - `two-much-01.jpg`, `two-much-02.jpg`
   - `kumbharwada-01.jpg`, `sassoon-dock-01.jpg`
   - etc.

You can reference these files directly in `assets/js/projects.js` using relative paths like `"assets/images/my-photo.jpg"`, or use direct cloud image URLs (Unsplash, Cloudinary, AWS S3, etc.).
